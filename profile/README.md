Computer engineering students in the Philippines. We build web, mobile, and desktop apps, and the backends and APIs behind them. Client work runs through [CoeDevs](https://coedevs.vercel.app), our agency.

### How we work

- **One engineer per layer.** Frontend, backend, and mobile each have their own owner.
- **A live build every cycle.** You test working software on a real link, not screenshots.
- **You approve the release.** Nothing goes to production until you sign off.
